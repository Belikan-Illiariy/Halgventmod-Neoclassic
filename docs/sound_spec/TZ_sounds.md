# Звуки боя, брони и голоса — техническое задание

Документ для подключения звуков в мод **Halgventmod: Neoclassic**. Звуки уже подобраны, переведены в формат Майнкрафта и разложены по папкам мода; `sounds.json` собран. Осталось зарегистрировать события, добавить субтитры и подключить звуки к тому, что уже есть в игре.

Что в пакете: **74 звуковых события, 372 файла** (удары, блоки, замахи, луки и арбалеты, надевание брони, позвякивание лат, снаряжение, состояния персонажа, 5 голосовых наборов, крики мобов). Музыки и звуков окружения здесь нет: у них свои ТЗ (`TZ_biome_music.md`, `TZ_atmosphere.md`).

---

## 0. Как работать с этим заданием

1. **Сначала изучи проект**: реестры в `registry/` (образец — `ModEffects`), датаген (`DataGenerators`, `ModLanguageProvider`), броню (`ArmorPieceItem`, `ArmorSlot`, `ModArmor`/`ArmorInfo`, `ArmorInventory`, окно брони), выносливость (`needs/Stamina`), сеть (`ModNetwork`). Задание написано по копии кода с GitHub от 2026-10-08 (коммит `839acd0`); локальная копия новее, сверь. **Если в коде уже есть механика боя по таблице `TABLITsA1.xlsx`** (типы урона, слои брони, щиты, «Повержен»), подключай звуки к ней, а не к ванили.
2. **Составь план по этапам** (раздел 11): какие классы появятся, какие файлы изменятся. Покажи план и дождись одобрения.
3. **Реализуй по одному этапу.** После каждого: сборка (`./gradlew build`), `runData`, проверка в игре (раздел 10).
4. **Решения, которые трудно отменить** (новые зависимости, миксины, формат сохранений), сначала обсуди с Bynelog.

**Не делать:**
- не менять механику урона, брони, выносливости и щитов: только звук поверх неё;
- не переименовывать, не перекодировать и не обрезать звуковые файлы: имена связаны с `sounds.json` и таблицей. Если файл звучит плохо, напиши об этом, а не правь;
- не класть `lang/*.json` руками: субтитры только через `ModLanguageProvider`;
- не делать выбор голоса `/voice` и вложение с набором: это этап 3 `TZ_character_fx.md` (разделы 13–14). Здесь только голос по умолчанию (раздел 6.7);
- не регистрировать события, которых нет в `sound_events.csv` (список недостающих в разделе 8);
- не менять голоса ванильных мобов (раздел 12, вопрос 4). Звуки оружия у мобов (арбалет у разбойника) меняются вместе с игроком, это допустимо.

**Соглашения проекта:** комментарии в коде на русском, короткие; все настраиваемые числа — именованные константы в начале класса, условные помечены ⚠️; переводы через `ModLanguageProvider`; CHANGELOG в два слоя.

## 2. Как это устроено в Майнкрафте (1.21.1)

- **`sounds.json`** описывает события: у каждого список вариантов, игра выбирает случайный. Вариант может ссылаться на другое событие (`"type": "event"`); так сделаны заглушки.
- **`SoundEvent`** регистрируется через `DeferredRegister<SoundEvent>` и `SoundEvent.createVariableRangeEvent(id)`: слышно на 16 блоков при громкости 1.
- **Проиграть**: на сервере `level.playSound(null, x, y, z, звук, источник, громкость, тон)` — слышат все рядом, включая самого игрока; `level.playSound(player, …)` — все, кроме этого игрока (он проигрывает у себя сам). Только у себя на клиенте: `level.playLocalSound(…)` или `SoundManager#play`.
- **Незарегистрированный звук** можно проиграть на сервере и разослать клиентам через `Holder.direct(SoundEvent.createVariableRangeEvent(id))`, если запись есть в `sounds.json` (так делает ванильный нотный блок; так задуманы голосовые наборы в `TZ_character_fx.md`, раздел 13).
- **Субтитр**: ключ `subtitle` в `sounds.json`, перевод в языковых файлах.
- **Подмена ванильных звуков**: `PlayLevelSoundEvent` (`AtPosition` и `AtEntity`, шина `NeoForge.EVENT_BUS`). Его можно отменить или подменить звук (`setSound`, `setNewVolume`, `setNewPitch`). Срабатывает в `ServerLevel#playSeededSound`, в `ClientLevel#playSeededSound` (ещё до проверки, свой ли это игрок) и в `LocalPlayer#playSound`; `playLocalSound` его не вызывает. Поэтому слушать оба вида и смотреть `getLevel().isClientSide()`. **На клиенте только отменять или подменять**, свой звук там вручную не запускать, иначе он прозвучит дважды. При подмене через `setSound` задавать громкость и тон из CSV (`setNewVolume`, `setNewPitch`): иначе останутся ванильные (у лука тон растёт с натяжением, взвод арбалета звучит на 0,5).

| Ванильный звук | Где запускается |
|---|---|
| `entity.player.attack.*` (удар игрока) | сервер, слышат все (событие срабатывает и на клиенте, но звук там не играет) |
| `entity.arrow.shoot` (лук игрока), `item.crossbow.*` | сервер, слышат все; у скелетов свой `entity.skeleton.shoot` |
| `entity.arrow.hit`, `item.crossbow.hit` (стрела из арбалета ⚠️) | сервер, слышат все |
| `item.shield.block`, `item.shield.break` | клиент, по событию сущности 29 и 30; слышит **только сам игрок со щитом** |
| `entity.player.hurt*`, `entity.player.death` | сервер для остальных и клиент самого игрока |

Ванильные крики игрока глушить в `PlayLevelSoundEvent` на обеих сторонах, по id звука (ими пользуются только игроки). Миксин на `Player#getHurtSound` и `getDeathSound`, возвращающий `null`, — запасной путь, если подмены не хватит; его сначала согласовать с Bynelog (раздел 0).

## 4. Регистрация: `ModSounds`

- Новый реестр `registry/ModSounds.java` по образцу `ModEffects`: `DeferredRegister<SoundEvent>`, `ModSounds.register(modEventBus)` в `HalgventMod` рядом с остальными.
- По константе на каждую строку `sound_events.csv` с непустой колонкой `java`: **57 событий**, id = `event`. Регистрируются **все**, и этапа 2, и этапа 3: потом коду механики останется только вызвать звук.
- Рядом с константой — английский и русский субтитр (из колонок `en`, `ru`), списком определений, как `ModItems.definitions()`: `ModLanguageProvider` проходит по нему циклом.
- **Голоса не регистрируются** (так решено в `TZ_character_fx.md`, раздел 13: новые наборы добавляются только ресурсами). Нужен помощник, который по id набора и виду крика собирает id `halgventmod:voice.<набор>.<крик>` и возвращает `Holder.direct(...)`. Виды криков — перечисление со своими субтитрами: `hurt_light`, `hurt_heavy`, `death`, `effort`, `drown`, `out_of_breath`, `warcry` (позже `downed`, `bandage`, `burn`).
- **Если в наборе нет такого крика — тишина**, а не чужой голос и не ошибка. Сервер не видит `sounds.json`, поэтому состав наборов пока держать списком в коде: у `male_1` и `female_1` есть всё, кроме `warcry`; у `male_2` и `female_2` только `hurt_light` и `death`; у `male_3` только `warcry`. Позже его заменят описания наборов `assets/halgventmod/voices/<id>.json` из `TZ_character_fx.md`.

## 6. Этап 2: подключить к тому, что уже есть

Строки с `stage = 2`. Ванильные звуки подменять только там, где в этом разделе сказано.

**Общее для серверных обработчиков**: `AttackEntityEvent`, `LivingEntityUseItemEvent.Start`, `LivingEvent.LivingJumpEvent` и `ProjectileImpactEvent` срабатывают на обеих сторонах, а `Stamina` отменяет первые два при изнеможении. Поэтому звук запускать **только на сервере** и с `priority = EventPriority.LOWEST`, проверив, что событие не отменено. Так же (`LOWEST`, не отменено) слушать `LivingDeathEvent` и `LivingUseTotemEvent`: их могут отменить другие системы мода. Таймеры криков и запомненные звуки стрел держать только на сервере: в одиночной игре клиент и сервер работают в одном процессе.

`LivingShieldBlockEvent` — исключение: в NeoForge 1.21.1 его отмена блок не снимает, щит смотрит только на `getBlocked()`. Поэтому слушать его с `priority = EventPriority.LOWEST, receiveCanceled = true` и решать только по `getBlocked()`; другие системы мода снимают блок через `setBlocked(false)`, а не отменой.

### 6.1. Надевание и снятие брони

- В описание вещи брони (`ArmorInfo`, билдер `.armor(...)`) добавить **материал**: перечисление `ArmorKind` со значениями `PLATE`, `MAIL`, `PADDED`, `LEATHER` (имя `ArmorMaterial` занято ванилью).
- По умолчанию по слоту `ArmorSlot` ⚠️: `HELMET`, `BREASTPLATE`, `GREAVES` → `PLATE`; `COIF`, `MAIL`, `CHAUSSES` (кольчужные шоссы) → `MAIL`; `BOOTS`, `GLOVES` → `LEATHER`; `CLOAK`, `ARMING_CAP`, `PADDING`, `TROUSERS` (штаны и тканевые шоссы) → `PADDED`. Если у вещи иначе — явно в билдере.
- Материал каждой вещи — в `armor_sounds.csv`: колонка `mod_id` для вещей, которые уже есть в моде (в том числе 4 вещи, которых нет в `TABLITsA1.xlsx`), `tablitsa_id` — для будущих. Кожаные перчатки и обувь в таблице записаны как «Ткань», здесь они `LEATHER`; украшения (плюмажи, бурлет, рондели) в файле тоже есть. Вещи мода из копии с GitHub: `bascinet`, `cervelliere`, `kettle_hat`, `bascinet_hounskull`, `greaves` → `PLATE`; `short_mail` → `MAIL`; `boots` → `LEATHER`; `hooded_cloak`, `quilted_aketon` → `PADDED`. `padded_jacket` и `halgvent_helmet` указаны по заметкам к таблице, в копии с GitHub их нет: сверь с локальным кодом.
- Звук: `armor.equip.<материал>` вместо `ARMOR_EQUIP_GENERIC` в `ArmorPieceItem.use`. В окне брони — только в слоте брони, в `setByPlayer(новая, старая)` на сервере (как у ванильного слота второй руки), один звук на операцию: материал новой вещи, а если слот опустел — снятой. Не играть ещё и в `onTake` или `quickMoveStack`, иначе звук будет двойным. Слышат все рядом.

### 6.2. Латы и кольчуга звенят на ходу

- Если на теле латы (`PLATE` в слоте `BREASTPLATE`, `GREAVES` или `BOOTS`) — `armor.move.plate`, иначе если кольчуга (`MAIL` в слоте `MAIL` или `CHAUSSES`) — `armor.move.mail`. Шлем и перчатки сами не звенят.
- Звук в такт шагам: раз на `STEP_DISTANCE` пройденных по земле блоков (1,8 ⚠️), на бегу громче (0,4 вместо 0,25 ⚠️), крадучись 0,1, в воде без звука ⚠️.
- **Считает каждый клиент сам** для всех видимых игроков: броня других игроков на клиенте уже есть (вложение брони рассылается, её видно на модели). По `TZ_character_fx.md`, раздел 15, при ходьбе и беге пакетов быть не должно.

### 6.3. Удары: какой звук

- Сервер, `LivingDamageEvent.Post`, **только ближний бой**: тип урона из нового тега `halgventmod:melee` (`minecraft:player_attack`, `minecraft:mob_attack`, `minecraft:mob_attack_no_aggro`) и `source.getDirectEntity() == source.getEntity()`. Без тега сюда попали бы взрыв крипера, шипы, луч стража и звуковой удар вардена.
- **Урон**: звук удара играть, если `getNewDamage() + getReduction(DamageContainer.Reduction.ABSORPTION) > 0`: золотые сердца поглощения тоже считаются попаданием. Ноль — удар принят щитом (раздел 6.8) или ничего не пробил.
- Звук в точке цели (на высоте груди), источник `attacker.getSoundSource()`.

**Вид оружия** атакующего, по тегам предметов (создать в датагене, ⚠️ состав):
- `halgventmod:sound/blade`: `#minecraft:swords`, `#minecraft:axes`;
- `halgventmod:sound/point`: трезубец (позже копья, кинжалы);
- `halgventmod:sound/blunt`: булава (позже молоты, палицы); всё прочее в руке тоже звучит как дробящее;
- пустая рука → кулак, **только если бьёт игрок**. Мобы без оружия в руке (волк, паук, зомби) звука удара не получают, их ванильные звуки остаются.

**Слой цели**: самый твёрдый материал в слотах туловища `BREASTPLATE`, `MAIL`, `PADDING`, по старшинству `PLATE` → латы, `MAIL` → кольчуга, `PADDED` или `LEATHER` → ткань, пусто → тело. Накидка не считается: латник в сюрко звучит как латы. Мобы → тело; моб в ванильной железной, золотой, алмазной или незеритовой нагрудной броне → латы, в кольчужной → кольчуга, в кожаной → ткань ⚠️.

| Оружие \ слой | латы | кольчуга | ткань | тело |
|---|---|---|---|---|
| клинок | `combat.hit.blade.plate` | `combat.hit.blade.mail` | `combat.hit.blade.padded` | `combat.hit.blade.flesh` |
| остриё | `combat.hit.point.armor` | `combat.hit.point.armor` | `combat.hit.point.flesh` | `combat.hit.point.flesh` |
| дробящее | `combat.hit.blunt.plate` | `combat.hit.blunt.soft` | `combat.hit.blunt.soft` | `combat.hit.blunt.soft` |
| кулак | `combat.hit.fist` | `combat.hit.fist` | `combat.hit.fist` | `combat.hit.fist` |

- Когда появится механика боя со слоями брони и местом попадания, звук выбирать по слою, который погасил больше всего урона в месте попадания (предложение ⚠️, в таблице «Урон» такого правила нет). Тогда же подключить `combat.hit.deflect` («удар соскальзывает со стали»), если удар не пробил твёрдый слой; на ванили его не играть.
- Ванильные `entity.player.attack.*` (strong, weak, crit, sweep, knockback, nodamage) глушить на сервере **только когда цель — живое существо**: в `AttackEntityEvent` поставить игроку флаг на этот тик. По лодке, вагонетке, рамке ванильный звук остаётся, иначе там будет тишина.
- Ванильный звук ранения цели остаётся у мобов; у игроков его заменяет голос (6.7).

### 6.4. Замахи

- Каждый замах оружием из тегов `sound/blade`, `sound/point`, `sound/blunt`: `combat.swing.heavy`, если предмет в теге `halgventmod:sound/heavy_weapon` (`#minecraft:axes`, булава, позже двуручное ⚠️), иначе `combat.swing.light`. Пустая рука и прочие предметы — без замаха ⚠️.
- Удар по существу: в `AttackEntityEvent` (сервер, см. начало раздела 6), раньше звука удара.
- Замах в воздух: на клиенте `PlayerInteractEvent.LeftClickEmpty` (только клиентское событие) — свой звук сразу у себя и маленький пакет на сервер, чтобы остальные услышали (`level.playSound(player, …)`). К этому моменту сила удара уже сброшена, поэтому частоту ограничивать своим таймером: не чаще раза в 0,5 с ⚠️.

### 6.5. Ножны

- Сервер, тик игрока: если игрок сменил выбранный слот и в руке теперь предмет из тега `halgventmod:sound/sheathed` (`#minecraft:swords`, позже ножи и кинжалы) — `combat.weapon.draw`; если такой предмет был в руке и его убрали сменой слота — `combat.weapon.sheathe` ⚠️. С клинка на клинок — только `combat.weapon.draw`.
- Не играть при входе в мир, возрождении, поломке и выбрасывании предмета.

### 6.6. Луки, арбалеты, стрелы

- `combat.bow.draw`: начало натяжения лука, `LivingEntityUseItemEvent.Start`, **только у игрока** (скелеты тоже натягивают лук через это событие), сервер, см. начало раздела 6.
- `combat.bow.shoot`: вместо ванильного `entity.arrow.shoot` от лука игрока. Скелеты стреляют со своим `entity.skeleton.shoot`, его не трогать.
- `combat.crossbow.load`: вместо `item.crossbow.loading_start` и `item.crossbow.quick_charge_1…3`; `item.crossbow.loading_middle` и `item.crossbow.loading_end` заглушить. `combat.crossbow.shoot` вместо `item.crossbow.shoot`. С «Тройным выстрелом» ваниль играет выстрел на каждую стрелу: от одного стрелка за тик оставлять первый, остальные отменять. У разбойников и пиглинов арбалет тоже зазвучит по-новому, это допустимо.
- **Попадание стрелы** (стрелы и болты, `AbstractArrow`; трезубец `ThrownTrident` пропускать). Ванильный звук попадания (`entity.arrow.hit`, у болтов `item.crossbow.hit`) звучит уже после того, как стрела нанесла урон или ударилась о блок. Поэтому свой звук не запускать отдельно, а **подменять ванильный** через `setSound` в `PlayLevelSoundEvent` на сервере:
  1. в существо: в `LivingDamageEvent.Post`, если `source.getDirectEntity()` — стрела или болт и урон вместе с поглощением > 0, выбрать звук по слою туловища (как в 6.3): латы или кольчуга → `combat.hit.arrow.armor`, иначе `combat.hit.arrow.flesh`;
  2. в блок: в `ProjectileImpactEvent` только на сервере (`!event.getProjectile().level().isClientSide()`), только `BlockHitResult`, по `SoundType` блока: дерево (`WOOD`, `BAMBOO_WOOD`, `CHERRY_WOOD`, `NETHER_WOOD`, `STEM`) → `combat.hit.arrow.wood`; камень (`STONE`, `DEEPSLATE`, `DEEPSLATE_BRICKS`, `DEEPSLATE_TILES`, `POLISHED_DEEPSLATE`, `TUFF`, `TUFF_BRICKS`, `POLISHED_TUFF`, `NETHER_BRICKS`, `NETHERRACK`, `BASALT`, `CALCITE`, `MUD_BRICKS`) → `combat.hit.arrow.stone` ⚠️ (блоки Conquest Reforged идут по своему `SoundType`). `ProjectileImpactEvent` **не отменять**: отмена отменяет само попадание, и стрела летит дальше;
  3. выбранный звук запомнить на этот тик по позиции стрелы, а в `PlayLevelSoundEvent` на сервере подменить им ближайший ванильный `entity.arrow.hit` или `item.crossbow.hit` ⚠️. Если ничего не запомнено (земля, песок, шерсть, лодка, рамка), ванильный звук не трогать. На клиенте эти звуки не трогать вообще.
  - Стрела, принятая щитом, звучит из щита (6.8): у отражённой стрелы ванильного звука попадания нет.
  - Звоночек стрелку при попадании в игрока (`entity.arrow.hit_player`) не трогать (раздел 12).
- `combat.arrow.fly`: на клиенте, когда летящая чужая стрела проходит ближе 6 блоков ⚠️ от игрока, один раз на стрелу, звук привязан к стреле (`EntityBoundSoundInstance`).

### 6.7. Голос по умолчанию

Это первая часть этапа 3 из `TZ_character_fx.md`: пока нет выбора голоса, **все игроки звучат набором `male_1`** ⚠️ (раздел 12). Код пишется так, чтобы id набора был параметром: потом его возьмут из вложения игрока.

Крик выбирается в таком порядке:

| Шаг | Условие | Крик |
|---|---|---|
| 1 | `LivingDeathEvent`, не отменено (позже «Повержен» будет отменять смерть) | `death`, без перерыва |
| 2 | в `LivingDamageEvent.Post` игрок `isDeadOrDying()`: удар смертельный, крик даст шаг 1 | ничего |
| 3 | урон от захлёбывания (`DamageTypes.DROWN`) | `drown` |
| 4 | голод и жажда (`DamageTypes.STARVE`), яд, иссушение ⚠️, позже кровотечение | ничего (`TZ_character_fx.md`, раздел 12) |
| 5 | огонь и лава | `hurt_light`, не чаще раза в 2 с ⚠️ (позже свой крик `burn`) |
| 6 | прочий урон по телу (`getNewDamage()`, без поглощения) > 0 и < 8 ⚠️ | `hurt_light` |
| 7 | то же, ≥ 8 ⚠️ (позже и начало сильного кровотечения) | `hurt_heavy` |
| 8 | спасение тотемом (`LivingUseTotemEvent`, `LOWEST`, не отменено: иначе при отменённом тотеме прозвучат и `hurt_heavy`, и `death`) | `hurt_heavy` ⚠️ |

- Отдельно: `effort` — удар по существу (`AttackEntityEvent`) или прыжок (`LivingEvent.LivingJumpEvent` только на сервере, `event.getEntity() instanceof ServerPlayer`, как в `Stamina.onJump`), не чаще раза в 2 с ⚠️; `out_of_breath` — выносливость упала до 0, начало изнеможения в `Stamina`, раз на изнеможение.
- Ванильные `entity.player.hurt*` и `entity.player.death` заглушить (раздел 2). Крик слышат все рядом, включая самого игрока; ползунок «Игроки», тон ±5 %.
- Перерыв между криками одного игрока не меньше 0,8 с ⚠️; смерть играет без перерыва.

### 6.8. Щит

- `combat.shield.raise`: игрок поднял щит, `LivingEntityUseItemEvent.Start` со щитом, только у игрока (сервер, см. начало раздела 6).
- `combat.block.shield.wood`: сервер, `LivingShieldBlockEvent`, **только при `getBlocked()`** (событие срабатывает и без поднятого щита). Ванильный щит деревянный. Слышат все рядом. Если в щит попала стрела или болт, вместо этого `combat.hit.arrow.wood`.
- `combat.block.broken`: щит выбит топором. Решается сразу после этого события, только не от снаряда: если оружие атакующего выбивает щит (`canDisableShield`, по умолчанию топор), играть его вместо звука блока ⚠️. Позже — и блок, на который не хватило выносливости (механика боя).
- Ванильные `item.shield.block` и `item.shield.break` глушить **на клиенте** (`PlayLevelSoundEvent`): их и так слышит только сам игрок со щитом, а новый звук приходит с сервера всем.
- `combat.block.shield.metal` (баклер, оковка) — этап 3, когда появятся такие щиты.

## 8. Заглушки и чего не хватает

- **Заглушки**: `combat.hit.blade.mail` играет `combat.hit.blade.padded`, `combat.weapon.dull` играет `combat.hit.deflect`. Код вызывает своё событие; когда появятся настоящие файлы, поменяется только `sounds.json`.
- **Один вариант** (повторы будет слышно): `combat.bow.shoot`, `combat.crossbow.shoot`, `armor.equip.leather`, `combat.heartbeat`, `mob.beast.death`, `voice.male_1.drown`, `voice.male_1.out_of_breath` и другие, см. колонку `status`.
- **Наборы голосов**: `male_1` и `female_1` полные (всё, кроме `warcry`). `male_2` и `female_2` — только `hurt_light` и `death` по одному файлу; `male_3` — только `warcry`. Неполные в окне `/voice` не показывать, пока не пополнятся.
- **Нет файлов, не регистрировать**: болевой шок, раскол щита, перевязка, ползание поверженного, перенос тела, падение отрубленной руки, ремонт металла и ткани, заточка, крики `downed`, `bandage`, `burn`. Что искать — в `sounds_table.xlsx`, лист «Бой, чего не хватает».
- Файлы подбирались по спектрограммам и замерам, **не на слух**. В `sound_files.csv` у некоторых есть заметка (обрезать тишину в начале, проверить хвост): это для Bynelog, не для кода.

## 10. Проверка

- `runData`: в `en_us.json` и `ru_ru.json` есть все 64 ключа субтитров.
- Лог при загрузке ресурсов без предупреждений о звуках (`does not exist, cannot add it to event`, `Missing sound for event`).
- `/playsound halgventmod:<event> player @s` для любого события из таблицы звучит; с включёнными субтитрами (Настройки → Специальные возможности) виден русский текст.
- В игре: надеть и снять каждую вещь брони; пройтись и пробежаться в латах и в кольчуге (второй игрок слышит); ударить зомби мечом, топором, булавой, кулаком; ударить игрока в латах и без брони; поднять щит, принять удар, получить удар топором по щиту; выстрелить из лука и арбалета в дерево, камень, землю, моба; ударить кулаком по лодке (ванильный звук остаётся); получить слабый и сильный урон, захлебнуться, умереть от одного удара (один крик, а не два), спастись тотемом; поголодать; бегать до нуля выносливости; сменить меч на меч в хотбаре. Ванильных звуков вместо новых и двойных звуков быть не должно.
