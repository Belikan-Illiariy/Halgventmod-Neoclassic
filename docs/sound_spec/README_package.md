# Звуки боя для Halgvent Mod: готовый пакет

Всё, что нужно Claude Code, чтобы подключить звуки в мод. Он сделает это по этапам из ТЗ.

| Что | Зачем |
|---|---|
| `resources/` | звуки уже по папкам мода и готовый `sounds.json`: копируется в `src/main/resources/` как есть |
| `TZ_sounds.md` | задание для Claude Code: что зарегистрировать, куда подключить, что пока оставить |
| `sound_events.csv` | одна строка = одно звуковое событие: субтитры, когда звучит, где подключить, громкость |
| `sound_files.csv` | одна строка = один файл: откуда взят, автор, лицензия, заметка |
| `armor_sounds.csv` | материал каждой вещи брони (98 из TABLITsA1 и 4 вещи мода, которых там нет): какой звук при надевании и звенит ли она на ходу |
| `CREDITS_SOUNDS.md` | авторы звуков, кладётся в мод (обязательно для части файлов) |
| `sounds_table.xlsx` | та же таблица звуков, что раньше, с новой колонкой `mod_file` |

Как отдать Claude Code (он работает в папке мода):

> Прочитай D:\Design\claude\sounds_for_mod\TZ_sounds.md и сделай по нему план. Файлы звуков и таблицы лежат рядом в той же папке.

Звуки подбирались по спектрограммам и замерам, не на слух: после первого этапа их стоит послушать в игре через `/playsound`.
