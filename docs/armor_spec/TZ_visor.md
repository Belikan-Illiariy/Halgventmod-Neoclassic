# ТЗ: забрало хундсгугеля, которое поднимается и опускается

## Контекст
У шлема `hundsgugel_bascinet` (Хундсгугель) появляется объёмное забрало «собачья морда».
Текстура забрала собрана из двух заготовок художника (пластина с дыхальцами и пластина со смотровой щелью),
которые раньше лежали на втором слое головы в `hundsgugel_bascinet.png` и из-за этого рисовались на самом шлеме.
Модель уже готова в формате, который мод грузит сам: `.geo.json` (Blockbench, «Bedrock Entity»),
`GeoModelLoader` → `ArmorLayer.renderDetails`. В модели кость `visor` (дочерняя к `head`) с осью на висках,
в заклёпках боковых накладок: точка `[0, 28.4, -1.5]`. Опущенное забрало — поворот кости 0, поднятое — поворот по X на **-80°**
(в радианах как есть, знак тот же: загрузчик переносит углы Bedrock без изменений).

Игрок нажимает клавишу — забрало надетого хундсгугеля поднимается или опускается, это видят все вокруг.

## Как работать
1. Прочитай этот файл, `docs/armor_spec/ARMOR_SPEC.md` и `docs/armor_spec/templates/BLOCKBENCH.md`.
2. Составь план по этапам ниже и дождись одобрения.
3. После каждого этапа — сборка, `runData`, проверка в игре, запись в CHANGELOG (оба слоя).
4. Перед правкой `ArmorLayer` и `ArmorRenderEvents` перечитай их свежую версию: они недавно менялись.

## Этап 1. Забрало на шлеме (опущенное)
- В `ModItems.HUNDSGUGEL_BASCINET` добавить `.armorModel("hundsgugel_bascinet_visor")`.
- Проверка: надеть хундсгугель — забрало стоит перед лицом, двигается с головой, на стыке со шлемом нет мерцания.

## Этап 2. Поднять / опустить
**Данные.**
- Компонент предмета `halgventmod:visor_raised` (Boolean, сохраняется и синхронизируется), в `ModComponents`.
  Нет компонента — забрало опущено. Состояние живёт на самом шлеме: снял и надел — осталось как было.
- В билдере `ModItems` новый шаг `.visor()` — «у вещи есть подвижное забрало: кость `visor` в её модели».
  В `ModArmor.ArmorInfo` — поле `boolean visor`. Без `.armorModel(...)` не имеет смысла: проверка при регистрации.
  Хундсгугель получает `.visor()`.

**Управление.**
- Клавиша `key.halgventmod.visor` в `ModKeys`, по умолчанию **V**, контекст IN_GAME, переводы ru/en через `ModLanguageProvider`
  («Поднять/опустить забрало» / «Raise/lower visor»).
- Нажатие → payload клиент→сервер (по образцу соседних в `network/ModNetwork`). Сервер берёт шлем из `ArmorInventory`
  (слот HELMET); если у него `visor`, переключает компонент на копии стака и кладёт её обратно через `set(...)`.
  Так срабатывает `onContentsChanged`, и броня уходит всем по обычной синхронизации.
  Звук на сервере, слышен рядом: что-нибудь железное (например, `SoundEvents.ARMOR_EQUIP_IRON`).
- Нет шлема или шлем без забрала — ничего не происходит.

**Отрисовка.**
- `GeoModelLoader` сейчас теряет имена костей. Сохранить имя в `GeoModel.Bone`.
- `GeoModel.render` принимает добавочный поворот для кости по имени (например, `Map<String, Vector3f>`).
  Добавочный поворот складывается с собственным поворотом кости из файла.
- `ArmorLook.Detail` запоминает, поднято ли забрало (берётся из стака при сборке вида; вид пересобирается по `version`,
  отдельного кэша не нужно). `ArmorLayer.renderDetails` передаёт -80° по X для кости `visor`, если поднято.
- Угол — именованная константа в одном месте, с комментарием, что он подобран под эту модель.

**Проверка.**
- V поднимает и опускает забрало; второй игрок видит то же.
- Снять шлем, надеть снова — состояние сохранилось. Перезаход в мир — сохранилось.
- Поднятое забрало лежит над лбом и не уходит внутрь шлема.

## Этап 3 (по желанию, после одобрения)
- Плавный поворот за ~4 тика вместо мгновенного (состояние анимации на клиенте, по игроку).
- Строка в подсказке шлема: «Забрало поднято» / «Забрало опущено».

## Не делать
- Не менять формат моделей и перевод координат в `GeoModelLoader` (кроме сохранения имён костей).
- Не трогать модель и текстуры забрала; если что-то не так — описать и спросить.
- Не добавлять игровых эффектов забрала (обзор, защита, дыхание) — см. открытые вопросы.

## Открытые вопросы
- Нужен ли эффект опущенного забрала: затемнение краёв экрана (узкие щели), меньше выносливости, защита лица?
- Какие ещё шлемы получат подвижное забрало (клапвизор, швайнсгугель)? Шаг `.visor()` для этого и сделан общим.
