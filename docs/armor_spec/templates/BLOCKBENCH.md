# Выступающие детали брони в Blockbench

## Начать
1. Blockbench → File → Open Model → `armor_model_template.geo.json` (формат «Bedrock Entity»).
2. Подключить текстуру `armor_model_template.png`, чтобы видеть фигуру игрока и голубую плоскость брони.
3. Сохранить как `.bbmodel` под именем детали и работать в нём.

## Кости
- `head`, `body`, `right_arm`, `left_arm`, `right_leg`, `left_leg` — точки крепления.
  Их не двигать и не поворачивать. Деталь кладётся **внутрь** нужной кости (можно в свои подкости) и движется с этой частью тела.
- `_reference_player`, `_reference_armor_plane` — подсказки (фигура, плоскость брони). Мод их не загружает;
  перед экспортом можно удалить или оставить — всё, что начинается с `_`, пропускается.
- Подкость с точкой вращения нужна там, где деталь будет двигаться (забрало: точка — на висках).

## Правила
- Деталь начинается от плоскости брони (голубая оболочка) и уходит наружу.
- Грани **не должны лежать точно в плоскости** брони: отступ хотя бы 0,1 пикселя, иначе мерцание.
- Кубики можно поворачивать на любой угол по любой оси.
- Развёртка — коробкой (box UV) или по граням (per-face UV); текстура любого размера.

## Файлы
```
assets/halgventmod/models/armor/<папка слота>/<id>_<деталь>.geo.json   File → Export → Bedrock Geometry
assets/halgventmod/textures/armor/<папка слота>/<id>_<деталь>.png       текстура детали
```
В коде вещи: `.armorModel("<id>_<деталь>")`. Готовых примеров в моде сейчас нет — за основу бери
`templates/armor_model_template.geo.json`.

## Проверить в игре без пересборки
Положить файлы в ресурспак с той же структурой папок (`assets/halgventmod/...`), включить его и нажать F3+T.
